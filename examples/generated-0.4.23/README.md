# 本轮真实生成结果

运行 `npm run results:restore`，校验后恢复到 `results/v0.4.23/`。

`*-before-fill.obj` 是本版纯几何生成、尚未填空的结果；`*-generated.obj` 是随后的本轮填空结果。都不是作者原UV。四个模型保留全部源3D面、填空前后裁片不变。

时间预算停止的填空在其他机器上可能停在不同的合法候选，因此参考文件保留了实际本次输出并锁定SHA256；原UV隔离测试比较的是不带时间停止精排的确定性生成。

本工具导入OBJ时会忽略其UV重新生成。精确比较这些文件，请用外部UV查看器。生成UV需要相应重绘或烘焙贴图。
