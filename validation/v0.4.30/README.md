## 本轮失败、修正与限制

1. 初始红回归在旧LSCM路径确实观察到宽度比1.483，并按预期失败。不是把旧断言跳过。
2. 首次新测试把两个独立、尚未装箱的局部片放在一起检查交叠；该测试错误已修正为逐岛检查。生产最终atlas仍全图检查，不放宽交叠阈值。
3. 原薄边测试写死`human-cylinder`方法名，本版改成实际`human-profile-strip`并额外验证矩形度量；面数、面归属、狭长比、最大形变等原断言保留。初次过期断言日志`regressions.txt`保留，最终`regressions-2.txt`通过。
4. 第一次新浏览器与整模隔离测试并发时，四项后CDP停止响应；该次取消，`browser-first-incomplete.json`明确未完成，不能计为12项通过。减少额外渲染开销、结束整模任务后串行重跑12项完成；不把该观察推断为已确认内存根因，也不承诺所有机器的全效果流畅性。
5. 一次Worker组合前台命令被外部120秒时限中止，之后独立后台会话完整跑完9项；没有后台工作留待用户等待。
6. `npm install`在25秒限额中未完成，退出124；实际完整build退出127缺Vite，完整typecheck退出2缺Node类型。对应日志完整保留。没有用语法转译/核心编译冒充完整UI类型检查。

截面边缺失、偏心/分叉、自适应无规律重网格的输入不保证识别；失败仍由明确的普通几何路径处理，不套矩形/环形外框。此次不改变填空策略、源几何、动画时钟或相机逻辑。
