# v0.4.16 · 统一动画时钟与手绘轮廓优先

本版在 v0.4.15（827629f）的完整 Git 历史上继续开发。旧 tag 原样保留。只使用仓库中已经校验的正确 Corset / FlightHelmet 夹具；没有重新使用此前的错误模型 ZIP。

## 1. 落位亮显／渐隐现在属于同一动画时间轴

上一版独立实时时钟是错误的产品选择：0.8 秒保持 + 1 秒渐隐不会被播放倍率压缩。本版移除该时钟、越过终点的事件缓存和单独推动淡出的 RAF，直接按当前动画位置采样。

对岛 i，设其完整几何落位时刻为 E_i、当前 1× 动画时间为 T，显示年龄就是 T−E_i。前0.8动画秒保持原色，随后1动画秒按 smoothstep 过渡到背景。几何、轮廓、颜色、编号使用同一采样权重。

| 倍速 | 实际亮显时长 | 实际渐隐时长 |
|---|---:|---:|
| 1× | 0.8秒 | 1秒 |
| 2× | 0.4秒 | 0.5秒 |
| 4× | 0.2秒 | 0.25秒 |
| 16× | 0.05秒 | 0.0625秒 |

播放中切换倍率不会归零。倒放、前后拖动、直接跳到同一进度，得到同一亮显/渐隐状态；按住拖动但停止改变进度时，不会随着墙钟继续变淡。高倍速可能因为帧率不足错过中间显示帧，这是倍率的真实结果，不再加一个“看起来更久”的未缩放时钟。

界面两个时长明确标为 **1×动画秒**。展示尾段仍与下一岛重叠，不阻塞接力、不把静止的展示时间重新插入几何运动队列。暂停、松手、取消、自然结束仍立即恢复原上下文。最后一个岛到达队列终点时恢复普通显示，不额外延长播放。

## 2. 根因：几何有效不等于适合手绘

旧 auto 路径先求解 LSCM；失败后使用正权重 Tutte，并把整圈边界固定到圆周。它解决了某些退化/翻面问题，却没有把轮廓可辨识性作为目标。除此之外，少岛策略会将正面、背面、侧壁连成不易辨认的片，再重新参数化；并非每个不易辨认的结果都来自 Tutte。

本版新增 **UV目标**：

- **手绘轮廓优先（默认）**：保留已有有效轮廓；尽量让齿形、孔洞、主要面板边界保留意义。不能通过形状检查的合并被拒绝。
- **少岛稳健 · 旧圆边界回退**：保留旧取舍，允许圆边界回退，不宣称适合直接画贴图。

求解器里的“强制圆边界 Tutte（诊断用）”仍是显式覆盖，不在选择后假装已经使用手绘保形。圆形本身不是错误：原本的圆盘、圆环、圆形底座仍可合理地呈圆形。禁止的是为了求解方便将无关轮廓统一压成圆，而非删除所有圆形岛。

### 2.1 保留有效原岛，缝合优先作相似变换

整理源UV时，正常原岛仍从原布局开始；不为了新模式重算所有原岛。缝合先尝试沿真实共享边进行旋转、平移和统一缩放。不能这样连接时，才尝试联合求解。

每次候选还要对照**本次处理开始时固定的各个原岛轮廓**，不是只比对上一轮已经变形的中间结果，避免多次“小变化”累积成完全不同的形状。默认上限1.5，范围1–4；1最严格。度量为去除整体相似尺度后的边长变化比，按源3D面积取99%分位。它不是语义相似度或对所有细小特征的严格保证；极小面积细节仍需要人工检查。

多保留几条可读的接缝，优先于把几块勉强并成一张难辨认的皮。不会把本来不相连的附件凭空焊成同一个岛，也不改变输入几何。

### 2.2 真正平面的区域保留轮廓与孔洞

对可验证的近共面面片，先使用其自身平面基展开，不强行规定圆边界或删掉孔洞。候选通过全部UV三角形检查才接受。

生成路径还会提取占比足够大的连通共面区域（至少16面、至少整体表面积2%），将主要平面面板与侧壁区分。剩余侧面用粗粒度区域处理，不把每个齿面都切成一块。内置Low齿轮因此得到5个岛，其中两个正反面保留完整齿形和中心孔；旧路径是4个难辨认的大拼接片。

不是拿某个固定相机视角做投影；任意曲面投影可能重叠，因此不能把它当作通用自由曲面解法。

### 2.3 曲面自由边界求解，不接受圆周回退作为默认最终结果

曲面先尝试现有自由边界LSCM。失败后可用有效Tutte作**数值初始状态**，再用本版独立TypeScript实现的自由边界ARAP局部/全局迭代，解开边界约束。默认24次外迭代，可调1–100；平移自由度由单点固定，不把边界顶点锁成圆。

每一步进行方向/能量回溯，最终独立检查翻面、退化、正面积重叠与极端三角形形变。ARAP最终最大各向异性大于100的候选直接拒绝，避免极小面在面积加权目标里被压扁。失败时保留原来分开的有效岛或由生成路径明确补切，不悄悄把圆形结果作为成功返回。

ARAP只优化几何畸变，不认识“袖口、肩、脸、齿轮正面”的语义。非可展曲面仍需要形变或接缝；本版不是自动服装纸样生成器，也不保证任何模型都符合人工绘制习惯。

### 2.4 加强最终输出检查

本轮真实头盔验证发现一个极细的相似变换缝合交叠，独立几何检查面积约1.0e−13 UV²，旧SAT接触容差未发现。本版将归一化接触容差从1e−10收紧为1e−12，新增真实反例回归；最终新候选被重新计算/拒绝，而非放宽独立检查。

所有新atlas在打包后、建立动画对应前，再逐页检查实际输出三角形。原样检查不被此规则改写，仍允许用户对照原UV。

## 3. 实际结果：轮廓优先有明确代价

以下对照没有执行额外填空，不能拿它与此前90秒精排后的占用率直接比较。

| 模型 | v0.4.15整理岛数 | 新手绘目标岛数 | 旧普通排布占用 | 新普通排布占用 |
|---|---:|---:|---:|---:|
| 正确Corset | 79 | 92 | 66.92% | 57.55% |
| 正确FlightHelmet | 130 | 173 | 62.49% | 40.71% |
| 内置Low齿轮 | 4 | 5 | 41.36% | 27.75% |

占用率下降真实存在，没有隐藏。保留凹口/孔洞、更保守缝合会让普通矩形装箱更难。原有轮廓精排仍可另行开启，它只旋转、平移、等比例缩放岛；本轮没有重新测量这两份新形状精排后的最佳占用率，也没有为了占用率抹平轮廓。

源轮廓审计：Corset的96个原来有效的源岛中，88个保持相似形状（边比误差<1e−5），其余在形变阈值内，最大1.349754；头盔235个原来有效源岛中202个保持相似形状，最大1.492194。无效原岛经局部修复不纳入“保留原形”统计。这个统计对象是原岛子区域，不是新岛数。

新结果保留18,324 / 94,722个源面；生产检查及导出后独立GEOS/Shapely检查均没有翻面、退化或正面积重叠。所有3D顶点和面顺序不变。审计并不证明人工语义可辨识性的普遍改善，具体轮廓仍应看真实对照OBJ。

内置程序褶皱服装的Low版本两种目标均为10个LSCM岛，本轮没有改变它。不得将它写成人台的替代认证。人台模型里原有圆形底座/附件也不因为本版而被故意改成非圆形。

## 4. 操作

在 **UV → UV目标** 选择“手绘轮廓优先”，求解器保持“自动”。设置原形变化上限与迭代预算，再使用“Extract + 整理原UV”或按配置重跑当前模型。无原UV的齿轮可使用Generate baseline/重新生成。修改目标不会悄悄覆盖已经完成的UV，需要明确执行。

选择“原样检查”只看源UV，不触发保形重算。查看本次交付OBJ时也用原样检查，避免再次运行整理改变对照的岛编号。结果包内同时保留旧版本整理对照、新版本手绘目标结果及齿轮两种目标。

新UV通常需要重新烘焙贴图，本版不自动烘焙。现有多选面积排序、倍速、接力、静止跳过、自由相机、两级选择、框选、避遮挡和重叠提示继续保留。

```bash
npm install
npm run dev
npm run test:arrival
npm run test:arrival:browser
npm run test:arrival:workbench
npm run test:paint-shape
npm run test:paint-shape:browser
npm run test:uv-sliver
node scripts/verified-models-smoke.mjs --models examples/verified-models --out validation/local-paint --export --snapshots --config '{"timeBudgetMs":240000}'
node scripts/paint-reference-audit.mjs --root validation/local-paint --report validation/local-paint/reference.json
```

无需前端依赖的离线页仍是 `unfold-lab.html`，通用FBX/GLTF入口属于完整Studio，不假装在离线页支持。代码为JS/TS，无新增运行依赖；Python只用于额外独立QA。

## 5. 研究出处与界限

CGAL官方手册区分固定边界、自由边界方法，以及角度/面积畸变目标。libigl官方教程讨论局部/全局ARAP和参数化。本版是独立TS实现，不等同于CGAL/libigl求解器，不依赖它们运行。

- https://doc.cgal.org/latest/Surface_mesh_parameterization/index.html
- https://libigl.github.io/tutorial/
