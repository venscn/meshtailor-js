# v0.4.9 · 铰链重叠可视化

基于 v0.4.8 继续维护。针对同一岛内的同色三角形在铰链展平时重叠却看不清的问题，加入实时显示诊断；没有修改UV求解、邻岛缝合、参数化、动画几何或导出坐标。

## 默认即可看见叠合位置

动画工具页新增“重叠与面片识别”。保留原岛色，三角面轻微稳定明暗区分；同岛近共面叠合部分用橙色斜纹表示2层，用玫红交叉纹表示3层及以上。完全重合的同形面也有叠层提示，不只是给顶面换色。

默认排除普通前后遮挡；需要观察遮挡时，显式切换“视线叠层”。它标明包括遮挡、并非几何相交。可调条纹强度、相对容差，可关闭明暗辅助或整个重叠提示。关闭提示释放诊断缓冲。

提示是当前动画姿态的实时覆盖结果，不是最终UV预计算标记。所选面高亮边框与原有铰链/裁切线保留；鼠标事件不被提示层遮挡。切换设置不暂停、不重算、不移动相机或清空选择。

## 真实铰链教学网格

新增“加载铰链重叠示例”：4面、1岛的马鞍。真实铰链展平后有重叠，右侧和最终目标是有效菱形UV。该按钮会替换当前模型；可用反向播放对照重叠出现/消失。

[运行截图](images/overlap-0.4.9.png) 是离线工作台实测，不是服装人台/飞行头盔，也不是完整React Studio截图。

## 实现与限制

增加WebGL2可见表层、同岛叠层计数、条纹合成通道；不需要新npm包或浮点渲染扩展。正常播放没有CPU逐面两两交叉检测或GPU像素回读。额外绘制有GPU成本，缓冲最长边2048、约2M像素封顶，可关闭恢复原普通显示路径。

默认只看同岛、当前可见表层附近、近共面面片；不是精确3D自交判定，不保证发现深处、非平行相交或亚像素重叠。容差默认模型最长边的0.01%，另有线性深度精度下限；过大的容差可能把很近的面也算进来。不同岛间碰撞不属于本次诊断。

**解决的是可观察性，不是把实际重叠消除。** 没有为了画面干净而移动、隐藏三角形，没有将条纹消失当成UV质量认证。

完整使用/技术说明见 [OVERLAP_VISUALIZATION.md](OVERLAP_VISUALIZATION.md)。

## 验证

新增12项策略、42项真实GPU像素/层数、17项真实工作台交互通过。GPU测试包含共享边、完全/部分/三层叠合、反绕序、不同岛、普通遮挡、倾斜视角、容差、禁用释放及显式失败重试；工作台测试包含真实马鞍铰链、有效目标、播放/选择隔离、相机独立、resize和WebGL上下文恢复。

原有先岛后面39项、相机39项、接力28项、静止跳过28项浏览器回归，以及核心21、铰链17、选择20、缝合21、分页14、Worker4、布局13、Git工具22项均实际退出0。原生WebGL通用回归24项通过，另2项module Worker检查因受限测试宿主显式跳过；工作台套件中的真实classic Worker没有跳过。

严格核心TS检查通过；三个修改TSX入口语法转译通过。完整 `npm run build` 仍退出127（vite缺失），`npm run typecheck` 退出2（node类型缺失）；另行registry检查DNS失败。没有把离线测试或语法检查说成完整React/Vite构建成功。没有认证真实Corset/FlightHelmet、macOS/Windows/Safari或硬件GPU。

详见 [VALIDATION.md](VALIDATION.md) 和 `validation/v0.4.9/`。

## Git与运行

在现有Git历史上按功能/测试/修复/文档小步提交；旧tag不移动。新版本使用独立附注tag v0.4.9，交付含 `.git` 和可独立恢复的bundle。最终ZIP解压复验另见外部交付验证文件。

```bash
npm install
npm run dev
```

确认顶部0.4.9。无依赖的 `unfold-lab.html` 也已更新，可直接打开或使用 `npm run lab:serve`；该页仅支持其原有OBJ/内置模型，不伪装为支持完整Studio的FBX/GLB导入。
