# 3D ↔ UV 岛展开对应预览

版本：v0.3.0。用途是解释“原网格的哪一块面片，对应 UV 图中的哪一个岛”，不是重新实现 UV 求解器。

## 直接体验

启动 `npm run dev` 后，在主视口上方切换到 **3D ↔ UV 展开动画**。在左侧点击 **加载六岛立方体示例**，等目标 UV 计算完成，再拖动主视口下方的 0–100% 进度条或点击 **播放展开**。该示例是真正共享网格顶点的立方体，以十二条棱切出六个岛；不是六张没有对应关系的图片。示例按钮会替换当前网格，不会写入原始模型文件。

0% 时各面角处于原网格的归一化位置，裁切边显示在网格表面；100% 时所选面角进入右侧目标 UV 的对应位置。两侧具有相同岛颜色、相同岛编号，U 向右、V 向上。选择 **UV 正视** 可以消除左侧透视角度的影响，直接比较最终布局。相机不会因拖动进度而自动改变。

在已有模型上使用时，选择下列一种目标：

| UV 目标 | 数据来源 | 接缝来源 |
|---|---|---|
| 生成的 UV 调试预览 | 沿完整接缝划分的 charts，经现有平面投影和网格打包生成 | 当前生成/提取的完整 seamEdges，不随遍历步骤变化 |
| 网格原始 UV | 导入或生成网格自带的逐面角 UV，保留镜像、重叠和超出 0–1 的坐标 | 从原始 UV 提取，不叠加无关的 baseline 接缝 |

使用第一种目标前，可以在原有 **Seam source** 面板点击 **Generate baseline** 或 **Extract existing UV seams**。使用第二种目标不需要先生成 baseline；但所有面片必须有完整 UV，否则会明确报错。错误不会静默退回生成 UV，也不会保留上一个模型的目标。

## 范围与播放是两个独立选择

| 预览范围 | 如何选岛 | 同时展开 | 逐个展开 |
|---|---|---|---|
| 单个 UV 岛 | 岛列表单击；3D/UV 点击；上一个/下一个岛 | 仅该岛变形 | 单岛情况下等价 |
| 多选 UV 岛 | 勾选岛列表，或 Shift/Ctrl/⌘ 加选 | 所选岛同时变形 | 按选择数组顺序依次变形，已完成的留在 UV 位置 |
| 全部 UV 岛 | 选择“全部 UV 岛” | 所有岛共同变形 | 按岛编号顺序依次变形 |

从“全部”状态取消一个复选框，会进入“多选”并保留其他岛。要从零选择几个岛，先点击 **清空选择**。列表中的单击名称用于切换为单岛，复选框用于组合选择。列表每页最多 40 行，视图编号最多显示 48 个，但这些上限不会限制可变形的岛数量。

未选择的岛始终保留原始几何位置。可以选择半透明、实体或隐藏；这些是显示选项，不会删除原网格或改变导出的 UV。

## 进度、变换路径与操作

**进度是可逆的。** 拖到任意位置会暂停播放，可以从 80% 拉回 20%，不会累积数值误差或修改原网格。`3D · 0%` 和 `UV · 100%` 可直接定位。反向播放会从 UV 返回网格；循环在端点短暂停留后重新开始。

默认路径为“分离 → 展平 → 移入 UV 位置”。每个岛的局部进度中，0–20% 沿稳定方向移离网格，20–80% 变形到自身的平面 UV 形状，80–100% 移入最终 atlas。可调整分离距离，也可以改用直接插值到 UV。修改路径会重新计算当前进度，不依赖上一帧。

“同时展开”的时长表示整段时长；“逐个展开”的时长表示每个岛的时长，整段时长为每岛时长 × 所选岛数。逐个模式下全局进度会映射到每个岛的局部进度。改变范围、列表选择或播放顺序会暂停并从 0% 开始。普通点击面片时会保留被点击岛当前的局部进度，便于在 100% 检查它；加选会重置组合预览。

拖动旋转，滚轮缩放，右键拖动平移。`适配 3D 视角` 显示整个动画范围，`UV 正视` 正对 XY 目标平面。两侧的 UV 棋盘、颜色、编号可用于识别镜像和拉伸。棋盘只是 UV 对应示意，不是原模型的材质贴图。

## 从一条接缝追到 UV 面角

点击左侧当前变形表面的三角面，或右侧 UV 中的三角面，会选择相同岛，并在两边高亮该面。拾取使用当前变形后的顶点，不是原始网格上的静态射线测试。右下角显示：岛编号、原面片索引、每个角的源顶点索引、原始 3D 坐标和目标 UV 坐标。面片/顶点索引从 0 开始，岛的显示编号从 1 开始。

一条内部 3D 接缝通常对应展开后的两条边，分别属于接缝两侧。动画按 **面角** 建立独立渲染顶点，所以一个共享源顶点可以沿不同岛移动到不同 UV 位置；不能把一个源顶点强行绑定为唯一 UV 坐标。面角对应关系才是这次动画、拾取与导出共用的基础。

原 UV 存在重叠时，鼠标只能拾取屏幕上最上层可命中的面片。使用岛列表并选择“隐藏未选岛”可以单独检查重叠部分。原 UV 本身的重叠不会因播放动画而消失。

## 导出

左侧展开控制中的 **导出对应 OBJ + 目标 UV** 写出原始网格的 3D 坐标和当前目标的逐面角 UV。不是导出动画中间态，也不是导出视口归一化坐标。即使只预览了某几个岛，导出仍包括完整网格及全部目标 UV，确保与完整右侧 atlas 一致。

原有 **Export current OBJ + UV** 仍导出原网格及原有 UV；两者用途不同。新 OBJ 导出不保证保留源 FBX/GLTF/OBJ 的原始 UV 索引编号身份、材质或骨架。

## 边界和故障检查

生成目标依然是原有 planar debug UV，不是 ABF++/LSCM。曲面可能重叠或退化。动画只是展示 **已有** 对应关系，不是 UV 求解器的计算轨迹，不保证中间过程保长、无穿插或像实体纸片一样可折叠。该限制不会改变“动画终点 = 右侧目标 UV = 导出目标 UV”的对应关系。

接缝存在不等于产生多个连通岛。一些裁切仍保留面邻接连通性，会只显示一个岛；原 UV 模式仍可以保留岛内部的面角不连续性。增加真正切断面邻接的接缝，或使用六岛示例，可以观察多个独立岛。

展开画布使用原生 WebGL2，原来的遍历画布继续使用 Three.js。WebGL2 初始化失败、上下文丢失、UV 数据缺失或 Worker 报错会显示错误；可以使用重试入口。大网格需要更多内存，每帧更新成本与面数相关，未承诺在所有机器上实时流畅。没有引入 Python、训练模型或新增 npm 运行依赖。

## 开发入口与验证

`packages/uv/src/unfold.ts` 是纯数据和插值层；`workers/uv.worker.ts` 只生成一份快照；`useUVSnapshot` 管理取消及陈旧结果；`useUnfoldPlayer` 管理范围、进度、播放；`webgl-view.ts` 与 `uv-drawing.ts` 分别使用该快照渲染 3D 和 2D；`CorrespondenceInspector` 显示原面角坐标。

```bash
npm run test:unfold
npm run test:uv-worker
npm run test:unfold:browser
npm run test:browser
```

最后一条才是完整 React/Vite Studio 测试。原生浏览器测试与 Node Worker 测试均不替代它。执行范围、跳过的浏览器 Worker 检查及实际截图见 [验证记录](VALIDATION.md)。
