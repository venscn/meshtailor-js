# 结构模板驱动的可识别 UV · v0.4.17

依据本次对话和未完成方案继续实现，基线为已发布 v0.4.16，不重建旧 Git。

目标是先根据真实 3D 拓扑识别结构，再决定切缝和展平方法，而非先任意开缝、最后希望通用求解器产生可识别轮廓。人台底圈的两条红线对应“两侧切缝 / 两片”，同时提供单纵缝一片；不将两条线误解为只能单缝。

1. 检测上下边界环、共同轴、绕轴点序和显著面积。微小饰物不强套模板，未匹配的自由曲面保留已有保形流程。
2. 圆柱采用条带、截锥采用扇区、一般环带沿选定侧缝运行自由边界保形求解；保持上下边界和环向对应。真正平面的齿轮面继续保留齿形与孔洞。
3. 新切缝必须是原网格边；模板的边界及切缝受后续缝合保护。每片拓扑、翻面、退化、正面积交叠及最大形变必须通过，不删面、不修改源顶点。
4. 可配置单/双缝、轴向、侧缝角度、显著面积门槛。支持只重展选中的岛，未选择的岛不重求解。模板报告包含源面/边界映射和拒绝原因，不把几何匹配得分称为人类语义识别率。
5. 生产 Worker、Studio、离线工作台、动画终点及 OBJ 导出共用输出；旧动画时间轴、倍率、相机、选择不改。

验证使用包内已确认的正确 Corset / FlightHelmet 原始 glTF/bin。须验证人台原 #12、圆柱/截锥、旋转、非均匀采样、保护切缝、非法输入/取消，以及真实导出/浏览器。初期模型解析器仅支持固定夹具，不能冒充完整 Three 导入认证。

理论背景：CGAL Surface Mesh Parameterization 官方手册区分固定与自由边界、角度与面积畸变及可切割拓扑：https://doc.cgal.org/latest/Surface_mesh_parameterization/index.html 。本版为独立 TypeScript 结构规划，不是 CGAL/BFF 的复制或通用语义纸样算法。双曲率表面一般仍需形变；侧缝轴向是可配置约定，不是自动推断“衣服的正面/隐蔽面”。
