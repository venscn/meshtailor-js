# v0.4.19 · 修复默认入口保留矩形原 UV 的盲点

## 1. 根因及之前测试漏了什么

用户要求 UV 能对应主要表面特征，不是仅满足“无重叠、少岛、填得满”。旧版本在重新生成路径能够得到齿形正反面，但默认载入遇到完整原 UV 时走的是 `source-atlas`。内置 Low/Medium/High 齿轮的参数网格提供了整件物体共用的一张矩形原 UV；它没有跨岛重叠，原岛保形规则因此保留它。环带模板并不能替代整件壳体的空间分组。

实际复现：原 source 为1岛；旧默认整理为1岛、UV占用约98.80%。这张图保留了错误的手绘形状取舍。旧“generated 得到齿形”的测试不能证明此入口通过。首个开发提交先增加失败回归，随后修复，未改测试用另一个路径冒充。

## 2. 原 UV 有效性与轮廓相容性分别检查

在 `source-atlas` 的原岛有效性修复之后、结构模板和缝合之前，增加：

```
真实几何中的主要连通平面区域
  → 保留孔洞/凹口的平面候选，并检查候选无重叠
  → 比较对应源 UV 的边长比例（去除整体相似尺度）
  → 没有冲突：保留当前原岛
  → 存在冲突：只对包含冲突的原岛重新空间分组/开缝/剥展
  → 锁定真实分组边界，再运行验证缝合及排布
```

门槛默认 `sourceFeatureTolerance=1.15`，范围1.01–4。沿用面积加权99%分位的相似尺度不变度量；不是语义相似度。主要平面面积下限沿用 `peelFeatureArea`（默认模型总面积1.5%），并要求不小于该原岛面积6%，避免极微小平面触发整岛重组。

检测只依赖几何连通性、共面性、实际面角 UV；没有模型名称、固定岛编号、手填齿数的分支。不是看到 UV 是矩形/圆形就强行改掉。平面矩形原本就可以是矩形，圆柱侧壁也可以保留条带。

修复受影响原岛时不再次把被拒绝的原 UV 当回退答案。未冲突的其他原岛不因本检查重新求解，源几何和原 UV 不修改。其余原岛仍可能参与原有结构模板或验证缝合，这是后续步骤，不混为本检查的行为。

## 3. 默认和显式操作的边界

- 标准整理/自动载入、Extract + 整理原 UV：在“手绘轮廓优先＋自动求解＋允许切割”下默认检查。无需强制用户换新预设。
- 新开关 `sourceFeaturePolicy='preserve'`：明确关闭轮廓修复，仅用于旧效果对照；UI 默认勾选检查。
- 原样检查：保留原数据和1张矩形，不假装已优化。
- 手动只重排：不重新分割，岛数与裁切不变。
- 后续缝合/填空：继承 feature 分组和受保护接缝；不得再次吞并完整平面轮廓。未启用自动重切；对受保护主特征的旧切缝重切试验明确拒绝。
- 原来的通用生成路径仍保留，未改成特定齿轮输出。

UI 两套入口接入同一生产 Worker，日志显示新增阶段，报告区显示检测特征数/重展原岛数/组到岛对应。诊断 JSON 同样保留这些字段。阶段不是依据进度百分比猜测。

## 4. 齿轮结果

| 输入（同一默认源整理路径） | 三角面 | 原 UV 岛 | 新 UV 岛 | 精确保留轮廓的主要平面 |
|---|---:|---:|---:|---:|
| Low | 1,536 | 1 | 6 | 2，含完整齿形和中心孔 |
| Medium | 6,144 | 1 | 6 | 2，含完整齿形和中心孔 |
| High | 24,576 | 1 | 6 | 2，含完整齿形和中心孔 |

验证不是肉眼认为“像齿轮”：逐边检查两个主要平面 UV/3D 长度之比一致（最大/最小差小于1e-7），孔边界环保留，所有源面恰好覆盖一次；实际 OBJ 重读岛数一致。剩余4岛为侧面和过渡面，不把其带状结构也强改成齿形。

Low普通排布有效占用约30.90%，Medium32.13%，High30.46%；未额外填空。这不是占用率提高，也不能与旧扭曲矩形的98.80%比较成同质量压缩。填空只允许旋转/平移/有界统一缩放，不应重新扭曲轮廓。

## 5. 真实模型与非特例测试

正确的哈希固定 Corset/FlightHelmet 仍使用包内 `examples/verified-models`。本轮实际执行 source-atlas：96/177岛，全部18,324/94,722面保留；检查分别发现3/4个主要平面候选，没有冲突原岛，因此本检查重展0岛。关闭/开启本检查的实际导出 OBJ 逐字节相同。**这不是之前通用剥展预设的93/176岛对照，路径不同，不混用数字。** 未额外执行长时间填空；没有宣称本版减少这两模型的岛数。

另外通过改名、刚性旋转与统一尺度、OBJ往返、独立带孔平面、已有正确轮廓、异形非齿轮壳体、真正矩形平面、显式旧模式/关闭切割等回归。仍不声称解决任意物体的语义分组、衣片命名或普遍可辨识性。
