# v0.4.6：材质 UV 分框、导入断边诊断和有界展开距离

## 本版修复范围

本轮针对“Corset / FlightHelmet 仍碎、Extract 后重叠、简单网格飞出太远”。已修复源码中确认的材质信息丢失和无界分离；增加保守的断边修复、面积加权软阈值以及真实分裂原因统计。**没有获取这两个真实资产的几何二进制，不能保证它们已经变成多少个岛。** 内置齿轮和六材质测试片不是这两个资产的替代认证。

## 1. 原 UV 不该跨材质混画

旧 `geometryOnlyGLTF` 删除了 `materials` 和 primitive.material；之后的 Three 场景转网格也没有保留材质分组。因此不同材质自己的 UV 坐标被画进同一个 0–1 框。

现在只移除贴图依赖，保留轻量材质 ID、名称、primitive.material 和 BufferGeometry.groups 的逐面归属。原 UV 的接缝判定同时考虑材质边界。新资产缓存名为 `flight-helmet-domains-v2.glb` / `corset-domains-v2.glb`，旧的已丢失信息的缓存不会自动冒充新格式。

`Extract existing UV seams` 默认 **按材质分框**，可切换 **所有材质叠加（仅诊断）**。每框中的岛保留原 UV 形状、大小、相对位置和坐标；不是重新求解或装箱。3D 动画目标与右侧 UV 使用相同的显示偏移，拾取联动也使用它。导出只写原 UV，不写显示偏移，并写 `usemtl` 标签。

公开 FlightHelmet glTF 声明六组材质。材质不等于独立贴图：其中两组共享贴图，所以分材质展示是保守的分类，不声称恢复了六套不同贴图。Corset 的公开 glTF 声明一个材质，不能用“多材质混画”解释它的所有问题。

同一材质内的堆叠、镜像复用或真正错误仍原样保留；原始 UV 模式没有全局无重叠承诺。多个框也不代表新增 UDIM 或统一 atlas。OBJ 导出保留标签和坐标，不附原 MTL / 贴图文件；生成新 UV 一般需要重新烘焙贴图。

## 2. 默认有界分离，不再按岛数铺开巨大网格

旧铰链布局用全部岛中最大的半径决定网格间距，再按岛数铺开。分离滑杆只是额外间隔，所以设小值也无法消除巨大的基础排布。

新规则：导入后模型包围盒最长边为 L，分离距离为 `d = r × L`。默认 r = 0.12；界面显示“12% 模型最长边”，允许 0–50%，API 同样限制到 50%。选中一个、多个、全部岛，队列顺序或某个岛半径都不会改变同一岛的分离位置。

点击 **原位展开** 将 r 设为 0；静止检测会去掉无动作的分离阶段。始终可以使用一次性的 **适配当前面片（保留观察方向）**，不会重新锁住手动相机。逐岛接力、反向播放、跳过静止时间、源/目标精确端点继续保留。

这个上限限制的是**额外分离平移**，不是把所有中间三角面强塞进固定盒子。展开本身可能把长曲面拉成长平面网；紧凑工作区也不保证岛间不相交。没有为迎合画框而缩放刚性三角面或歪曲最终 UV。

## 3. 细碎：导入修复和求解诊断分开

### 导入微小断边

FBX / GLB / glTF 默认位置模式现在是 **Boundary**：先沿用每源对象的精确位置焊接，再匹配唯一、反向、端点都在容差内的完整边界边。默认容差 `5e-7 × 该源对象最长边`。

只在同一源对象/实例内工作，不跨对象把相近部件焊起来；不对任意邻近点普遍吸附；非常短的边和多个候选的模糊配对被跳过。如果配对引入退化、重复三角面或新的非流形连接，则回滚该对象的补接。UV 面角数据不合并、不移动；补接会让极小的几何断缝使用共同代表顶点，并不是字节级保留所有输入坐标。已有的零面积导入面处理仍在报告中。

可选择 Exact / Tolerance / Off；更换导入设置后必须重新载入模型。精确重合但实际上独立的同对象壳层仍可能被原有的精确焊接合并，不能从坐标自动判定语义。不得无限扩大容差来追求更少岛。

### 面积加权的软形变控制

大块策略默认 **99% 源表面积**要达到软形变限值；不让占面积极小的单个极端三角面决定整岛反复补切。超过软阈值的实际面积比和真实最大值仍报告。所有面参与 UV 求解，翻面、退化、正面积重叠检查仍覆盖全部面。

这不是“丢掉 1% 的面”，也不是放宽无重叠条件。它允许很小面积的局部形变较大，是质量取舍，不保证更少岛或更高质量。将比例设为100%或使用“均衡”恢复严格最差面控制。拓扑、单岛面数预算、求解无效、长宽比等仍可能导致补切。

### 分裂来源与本地诊断

生成完成后显示：源几何连通分量 → 初始区域 → 最终岛；小于16面的岛数；补切原因。`topology` 是拓扑条件不满足，`face-budget` 是面数预算，`solver-invalid` 是求解或有效性失败，`stretch` / `aspect` / `fill` 分别是软形变 / 长宽比 / 填充阈值。窄缝但不拆岛的成功修复不算一次岛分裂。详细事件最多保留1000条，超出数单独报告，总计不截断。

**导出分割诊断（不含模型几何）** 在 Studio 和离线页都可用。JSON 包含本地模型名称、面数/顶点数、设置、材质框、岛统计、错误/警告和耗时，不包含位置/面列表、不自动上传；模型名称可能具有私密性，分享前自行检查。源 UV 模式不运行生成求解器，因此没有生成补切原因。

## 操作顺序

解压新目录，停止旧服务后运行 `npm install`、`npm run dev`，确认 `Studio · 0.4.6`。

重新获取远端资产（旧版本丢掉的材质信息不能靠重新分组猜回来）：

```bash
npm run assets:download -- --only flight-helmet
npm run assets:download -- --only corset
```

再次点击在线模型入口重新导入，位置焊接保持 Boundary。要查看原布局用 Extract，保持“按材质分框”；要重做大块用“自动参数 · 大块重分割”。动画默认分离12%，不需要分离时按“原位展开”。

真实资产诊断入口（需要本地 npm 依赖和真实 GLB，本轮未执行成功）：

```bash
npm run test:sample-asset -- --asset flight-helmet --report helmet.json
npm run test:sample-asset -- --asset corset --report corset.json
# 也可以提供用户自己的、包含原材质信息的 GLB
npm run test:sample-asset -- --file /path/to/mesh.glb --target source --report source.json
```
