# v0.4.8：连通优先分割、真实邻岛缝合、连接感知分页

## 本次解决的问题

此前材质分框只是在查看源UV，不能减少碎岛，也不能检测同一材质内很多岛完全叠在一起的情况。本版把“看到原始UV”“重新分割”“缝合现有岛”“只重排”和“分配新UV页”分开，不再把其中一种操作说成另一种已完成。

新入口位于左侧 **UV → 减少碎岛 · 前处理 / 后处理**：

- **前处理：连通优先重分割 + 自动缝合**：替换当前接缝，从3D真实连通分量开始，只做必要补切，再验证邻岛合并。
- **后处理：缝合当前邻岛**：捕获当前完成结果，优先长共享边界/连续法向的邻岛，移除共同接缝后重新参数化；成功才提交。
- **只重排当前岛**：不减少岛数，修复岛与岛之间的叠放；不把岛内部折叠当成已修好。

原UV现在显示真实岛数、每源材质域的正面积重叠与退化数。重叠数达到100对时是下限；有意镜像或贴图复用仍保留。Extract不自动缝合，也不改源UV。原baseline入口仍使用原来/当前策略，新前处理需要主动点击。

## 新页不再按材质编号切分

新atlas默认单页；可选择“连接紧密的岛优先同页”与“每个几何连通组一页”。分组依据真实共享边界图，不以UV距离或材质相同代表连通。多页目标是软目标，断开的组件不会被强行视为一组；各页共同纹素密度，页归属真实进入导出。源UV材质分框则继续作为不改原坐标的对照模式。

新atlas使用新的页域，修复跨旧材质缝合后OBJ回读又被旧材质域拆开的情况。原始模式保留旧坐标/材质；新atlas需要重新烘焙贴图，本版不自动烘焙或生成MTL。

## 已测效果（内置Low，不是真实人台/头盔）

| 网格 | 保留的原分割路径 | 连通优先 + 验证缝合 |
|---|---:|---:|
| 齿轮，1536面 | 4岛 | 2岛 |
| 程序褶皱服装，3072面 | 10岛 | 1岛 |
| 三叶结，2304面 | 7岛 | 2岛 |
| 多部件机械件，5632面 | 31岛 | 8岛 |

全部源面覆盖、生成UV有效性、源输入不变和导出回读检查通过。两面板合成浏览器例从12个重叠岛缝合到2岛；只重排仍是12岛。页面截图明确标记为测试片。

这不是对所有模型的岛数承诺。机械件路径耗时从本机约0.23秒增加到2.53秒；三叶结新布局有效占用约18.5%。岛更少不一定填得更满，不能靠压扁或重叠来刷占用率。预算/拓扑/形变拒绝会显示，不保证全局最小岛数。
