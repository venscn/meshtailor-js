# MeshTailor-JS v0.3.0：3D ↔ UV 对应展开预览

本版在原 Git 仓库的 `3b25acb` 之后继续开发，不重建历史、不移动 `v0.1.0`、`v0.1.1`、`v0.2.0`。新增独立附注 tag `v0.3.0`。ZIP 包含 `.git/` 和完整 bundle，解压后可直接查看小步提交。

## 新增功能

主视口增加“3D ↔ UV 展开动画”页签。可拖动 0–100% 进度，正放/倒放/循环；支持单个、多选、全部岛，与同时/逐个播放自由组合；未选岛可半透明、实体或隐藏。提供分离距离、时长、路径、UV 正视、棋盘、编号和一键六岛立方体示例。

3D 动画与 UV 面板共享同一份 chart/face/corner 对应关系。按面角拆分接缝两侧，从原网格位置移到同一目标 UV。可在两侧点击三角面联动选择，查看逐角 3D → UV 坐标，导出包含该目标 UV 的 OBJ。目标既可以是完整接缝的生成预览 UV，也可以是网格原始 UV。

原有遍历、复杂样例、FBX 导入及资产入口保留。新增动画画布使用原生 WebGL2；原有遍历继续使用 Three.js。没有添加 Python 或 npm 运行依赖。

## 使用

```bash
npm install
npm run dev
```

顶栏显示 `Studio · 0.3.0`。切换到 **3D ↔ UV 展开动画** → **加载六岛立方体示例** → 拖动进度或播放。使用自己的模型时，先生成接缝，或在展开控制中直接选择“网格原始 UV”。详见 `docs/UNFOLD_PREVIEW.md`。

## 必须区分

生成 UV 仍是原有平面投影调试预览，可能重叠或退化；没有完成新的高质量 UV 求解器。动画是可逆的面角对应变形，不是物理展开，也不是神经模型或 ABF++/LSCM 的求解过程。
