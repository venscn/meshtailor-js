# v0.4.30 · 重复剖面的等宽展开与环件保孔

## 问题与复现

用户截图为内置 Mechanical assembly 的中密度模型，22,528 个三角面、后缝合后 16 岛。选中的中央孔壁包含 2,304 面、192 条周向母线，每条母线的七层剖面完全相同。

这个面包括直壁和两端倒角，并不是严格的单半径圆柱。未归一化的几何剖面为 `(轴向高度, 半径)`：

```
(-0.16,0.50), (-0.13,0.475), (-0.10,0.45), (0,0.45),
(0.10,0.45), (0.13,0.475), (0.16,0.50)
```

每条实际3D剖面折线的长度均约0.356204993518133。旧直圆柱/圆台拟合不能容纳两端倒角，遂进入 `human-contour-band` 的自由边界LSCM；LSCM局部角度误差较小，不代表重复剖面会得到相同UV宽度。实测旧图最宽/最窄母线比为 **1.48328523878**，并非装箱、相机或用户误读。

## 实现

`revolved-profile.ts` 从真实几何 `(半径r, 轴向t)` 与边邻接恢复完整圆周截面、无分叉剖面图和可切开的完整母线。不读模型名称、程序样例元数据、原UV、原切缝或原岛。

### 周期侧壁：测量剖面，构造矩形

旋转面局部度量为 `ds² + r(s)² dθ²`。先按实际剖面累计 `h(s) = ∫ ds/r(s)`，再取 `R = 剖面总长 / h总长`，映射为：

```
u = R × 周向角度
v = R × h(s)
```

四条边由几何中周期与剖面的方向决定，不是将已有歪斜UV的外框拉直。剖面内的倒角和全部三角面保留；开口吸附到一条实际存在的完整母线，而不是某层的斜对角线。记录实际吸附角偏差。

相同周向剖面得到相同宽度。对这块真实孔壁，长宽比为 **8.12199510936:1**，宽度比 **1**，最大局部方向拉伸比 **1.02957672438**。不同半径的倒角并不能无伸缩地铺成一张等宽矩形；此处仍存在小量形变，不能声称完全等距展开。

### 浅径向环件：先保留孔，不先开径向缝

对完整双边界、主要沿径向延伸的轴对称剖面，先用 `rho = 内圈半径 + 累计剖面长度` 建立环形候选，保留外边界和真实内孔。剖面即使存在厚度回折，也不靠直接投影把它们叠在一起。

正确 Corset 中三个288面环状件均通过，单件仍是一个岛、两个边界环，不再先开成带缺口的“蜗牛”形。此映射保留径向剖面长度，但周向形变有代价：最大局部方向拉伸约 **2.25084**，高于上一版肩环开缝后的约1.98/1.90。超过用户形变门槛则不能接受，不会为了得到圆环而放宽翻面、退化、交叠检查。

这不意味着任意圆柱都应成为圆环，或任意有孔曲面都能直接保孔；两种候选按几何剖面方向区分。

### 全过程检查

- 实际切边必须是网格边；所有面恰好覆盖一次。
- 验证每个三角形、边界简单性、形变与面积塌缩门槛。
- 矩形四边必须对应完整母线和两个圆周边界，不能出现“直外框、内部乱接”。
- 将参考坐标绑定到每个切割后顶点，并在普通排布、后缝合、重排、填空之后检查实际输出。
- 后处理只允许整体旋转、移动和等比例缩放；同时复核全部面角连续性、孔数、开缝与面集合，不接受只修改未采样角点的篡改。
- 不删除、不移动3D顶点；不使用原UV恢复失败候选。

## 使用

在 **UV → 结构模板** 保持 **“重复剖面度量展开（等宽侧壁 / 保孔环件）”** 开启（初始默认），UV目标为手绘轮廓优先、求解为自动。重新载入 Mechanical assembly 或 Generate baseline，随后缝合/填空仍保留矩形。

Inspector显示剖面层数、矩形长宽、真实面数、形变上限和是否保孔。主Studio与离线工作台共用算法；离线页面实测，主React入口构建限制见验证记录。

关闭此选项可以比较旧的自由边界路径；这是明确控制项，不是后台自动退回源UV。显式一片/两片、每岛面数预算、圆台扇形、闭合管身横向分段仍保留。

```
npm run test:revolved-profile
npm run test:revolved-profile:worker
npm run lab:build
npm run test:revolved-profile:browser
npm run results:profiles
```

## 真实结果与界限

- Medium机械件：全部22,528面，16岛不变；三块2,304面孔壁均为完整等宽矩形。不同实际剖面导致各孔壁长宽不同，不强制等尺寸。
- 工厂默认Corset：全部18,324面，81岛；开启后缝合时80岛。三个288面环件都保孔。
- 工厂默认FlightHelmet：全部94,722面，191岛；输出与v0.4.29一致，未宣称本轮改善其他大曲面。
- 正确人台/头盔各携带原UV、删除UV、随机UV三变体，切线、逐角坐标和OBJ一致；这六条只测试生成，不用时间停止的填空来冒称确定性。
- 剖面识别要求完整圆周截面边和无分叉剖面邻接，半径/轴向残差阈值为最大半径的5e-5；有噪声、偏心、分叉或截面被任意重网格破坏的输入可能仍走一般路径。
- 不把真实齿形/褶皱强制成矩形，不把陡圆台扇形压成长方形。大空白、任意自由曲面的语义版型和贴图烘焙不是本版解决范围。

数学背景可参阅CGAL参数化手册对角度/面积与边界约束的区分：
https://doc.cgal.org/latest/Surface_mesh_parameterization/index.html
本实现为独立TypeScript，不依赖CGAL运行，也不宣称这些约束等同于零形变。
