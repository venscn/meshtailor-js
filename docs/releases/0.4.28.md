# v0.4.28 · 闭合管身的规则矩形展开

## 复现的是哪条错误路径

基线v0.4.27、内置三叶结Medium、9,216面、工厂默认纯几何生成。原环带识别只接受两个开口边界环；闭合三叶结没有边界，返回 `not-two-ring-band`。随后走通用开柄切图，新增285条内部开缝边，LSCM失败后从圆周种子进行自由边界ARAP，得到截图中的斜向、局部尖细形状。局部角度指标通过并不等于保住纵向/环向结构。

因此，修改发生在**结构识别、真实切缝和坐标生成**，不是在最终打包时把怪形状框成矩形，也没有放宽已有交叠容差。

## 1. 从几何恢复闭合管身

`packages/uv/src/tube-strips.ts` 在已有空间组内检查流形、闭合、Euler=0和显式切缝约束。沿真实有向边的平顺延拓发现闭合环，拟合几何截面圆；所选截面必须互不相交地覆盖全部顶点，每个三角面连接两个相邻截面，邻接图必须为单周期而不是空间近邻路径。结的两股靠近时不会跨空中跳接。

将截面方向与管长方向一致化后，动态规划求跨环相位对应，包括最后一环回到第一环的闭合条件。纵缝必须由真实边组成，不会每过一环偏一个采样点，最终走成螺旋斜线。

没有读取模型名、岛号、原UV、程序生成的行号、源切缝或源岛。识别覆盖不完整会拒绝，不会拿部分成功面冒充整管。

## 2. 四条有明确用途的边

先沿管身开纵缝，再在一个截面横向打开；用户可显式增加横向分段。参数坐标为：

- U：沿已识别截面中心轨迹的累计边长；
- V：对应截面周向边长的平均累计值。

相当于“沿管长剥开管皮，然后铺成条带”。整条长度来自实际离散中心轨迹，宽来自实际平均周长，不由单位正方形决定。

弯曲管面不是平面纸带；固定矩形引入受控局部形变。所有面检查翻面、退化、正面积重叠、切边界简单性、最大局部各向异性和面密度极值。每个输出矩形记录四角、四边样本、长宽比、真实切缝及全部源面，重排/缝合/填空后用实际输出重新验证，禁止抹掉横断缝、剪切或单轴拉伸。

**一条长矩形不能不变形就占满方形页。** 默认整条优先保留连续性；提高占用率的5段方案明确增加4圈横切，不是密度作弊、不删除面、不用重叠填满。五段数值不能冒称只改了装箱算法的收益。

Low/Medium均默认一条；High为36,864面，单岛面数预算要求至少2段，按顺序增加横断面而非退回任意二分。显式5段时三档均为5个矩形。每一档的逐面检查和实测数据见unit/report.json。

## 4. 使用

UV → 结构模板 · 人工切缝思路：

- `closedTubeStrips` / 闭合管身：默认开启。
- `closedTubePanels` / 闭合管身横向分段：1–64，默认1。
- `closedTubeMaxStretch` / 最大方向拉伸比：1.05–8，默认4；同时受原有更严格质量设置约束。

编辑这些选项后重新Generate baseline；参数变化不会立即重算。只重排、填空不会擅自新增横切。主Inspector显示当前岛实际长宽比和几何识别信息，不是固定贴上的“已矩形化”标签。两套UI共用该描述函数。

这些规则只在手绘/自动/自动开缝/结构模板启用时使用；显式诊断求解方式维持原语义。关闭新项可复现旧通用路径，不称其结果为新矩形方案。

## 5. 验证边界

21项生成回归覆盖Low/Medium/High、同一原UV删除/随机/抛异常getter、面/顶点重编号、四边对角线翻转/混合、旋转尺度，以及独立生成的普通圆管环、起伏闭合管和轻微变半径管。8项生产Worker回归包含自动填空仅一次、后缝合/重排/精排、边界契约和OBJ重读。11项实际离线工作台DOM/Worker/WebGL包含生成/切换段数/Inspector/最终对应/播放与自由相机。

正确Corset/FlightHelmet六条原/无/随机UV完整生成均重新运行。分别仍为84/191岛，导出SHA256与v0.4.27相同，没有将历史生成结果冒充本轮运行，也没有宣称本次改善它们的其他自由曲面。

本模块是**保守的几何截面族识别**：需要可恢复的近圆边环、相容的跨环连接和采样数量；分叉、任意自适应重网格、缺少完整横截面边或明显非圆的管状体未获通用保证。不将所有Euler=0表面都判定为矩形，也不强迫齿面和服装变成矩形。

当前矩形坐标使用平均周长，不是精确等距映射或能量最优保证；超过局部形变阈值拒绝。没有改变铰链路径为物理布料模拟，中间动画仍可存在临时断边/穿插。

原生产打包是独立旋转/统一缩放。本次未修改填空搜索算法，源面积政策和原有全部操作保留。原UV不参与生成和回退。

完整React/Vite实际build退出127、typecheck退出2；缺Vite/Node类型依赖。通过的浏览器测试是共享生产模块的离线页；未将其称为完整React/通用Three导入、macOS/Windows/Safari实机认证。

数值参数化背景可参考CGAL对固定/自由边界与角度/面积畸变的区别：https://doc.cgal.org/latest/Surface_mesh_parameterization/index.html 。本实现为独立JS/TS，不依赖CGAL运行，不声称它提供了管身语义识别。
