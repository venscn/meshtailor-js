# v0.4.21 · 先保留透孔主面，再展开闭合厚壳

## 修复范围，和未解决的部分

用户截图中的护目镜来自一个 **2,976 面、闭合、Euler=-2** 的几何连通块。旧分组把它整体交给开柄切图，再展开为盘。没有重叠并不表示保留了眼孔、外轮廓或手绘可读性。这不是装箱位置或相机角度的问题。

本版先从几何中找可验证的透孔主面，分开主面与回折/背面，再保护主面的孔和边界进行展开。**不是完整的人工语义展开器；不能宣称人台及头盔的所有曲面都已变得适合手绘。** 人台结果本轮与 v0.4.20 逐字节一致，没有改善其余一般曲面的分组依据。回折/背面仍由一般求解处理，可能仍不够直观；对照图没有将它隐藏。

## 生产改动

1. 以面积加权的几何主方向生成可见面候选，不使用当前相机、模型名、岛号或材质名。模型原 UV 坐标、索引、源切线、源岛提示始终不参与。
2. 在闭合多柄结构或多孔开口区域，寻找连续、正向、无交叠的可投影片。只有边界全部简单、孔面积足够、覆盖足够表面积的片才作为结构证据。普通单柄管环不因此被切成一堆小片；原有环带展开仍保留。现阶段不把这项判据泛化到所有闭合实体。
3. 法线阈值只是候选，不是最终切线。用既有窄带长度/折角图割调整 **真实三角面的分组归属**，再验证同样的孔数、连接性和投影可行性。没有移动3D顶点、删面或只在屏幕上平滑轮廓。
4. 以该片的几何投影为参照，做带边界与内部位置软约束的 ARAP。没有把原 UV 当初值，也没有把这项约束施加到不适用的一般曲面。
5. 额外检查孔面积、孔中心、全部边界顶点相对参照的变化：去除整体平移、正规旋转、统一尺度；不允许镜像作为拟合捷径。边界最大偏移上限为参考外框对角线的12%，均方根4%；孔面积比例0.5–2、孔中心漂移6%。这些是明确几何门槛，不是人工识别评分。
6. 普通三角形、切割边界检查仍然执行。最终排布、重排和填空后，再检查实际输出没有丢失受保护的孔或篡改分组，不是只验证一份已丢弃的初始状态。

相似旋转/缩放不改变孔和主轮廓关系；压成正方形或把孔切进星形外轮廓不是允许的“排布优化”。若受保护结构无法满足完整检查，操作失败并保留上一份完整结果，不会退回模型原 UV，也不发布半张 atlas。

## 当前真实护目镜结果

- 835个三角面组成主面，保留 **一个外边界＋两个眼孔**。
- 2,141个内壁/回折/背面三角面另行展开；全部2,976面恰好出现一次。
- 候选切线的局部光滑面尖齿代理由7降到0，实际移分193面；切线3D长度从1.2830降到1.0764（在该测试坐标系）。这是特定区域测试，不代表整个模型没有任何尖角。
- 主边界最大偏移为参考轮廓对角线的 **2.1577%**；两个孔在去除整体相似尺度后面积比例约 **1.0010、1.0211**。
- 不是按截图 #31 编号选主面；本轮工厂默认参数的主面显示为 #35。用户截图总数146与本轮默认193不同，截图没有完整配置，因此不声称逐项复现了截图时的所有参数。

`validation/v0.4.21/comparison.png` 用同一份几何和 v0.4.20 实际生成结果作比较，不用作者原 UV。各图独立适配大小，主面仅为读图整体旋转，实际导出未变；不能以小图面积比较纹素密度。

## 整体结果与代价

同一正确夹具、工厂默认纯几何生成、未额外填空：

| 模型 | 面数，全部保留 | v0.4.20岛数 | 本版岛数 | 本版有效UV面积 |
|---|---:|---:|---:|---:|
| Corset | 18,324 | 95 | 95 | 50.9234% |
| FlightHelmet | 94,722 | 192 | 193 | 55.4335% |

头盔不是通过少一个岛来改善；合理分离主面增加一个岛，占用率由55.9046%略降。没有用更高填充率冒充更好的可读性，也没有宣称人台全局有所改善。

两个真实模型分别携带原UV、无UV、随机UV生成：切线、逐面角坐标及OBJ逐字节一致。人台OBJ与上一版完全相同；头盔的变化来源是新的几何分组。独立Shapely/GEOS对实际OBJ的正面积交叠检查均为0，阈值1e-14 UV²。Python只是独立QA，不是JS项目的运行依赖。

## UI 和使用

保持 **手绘轮廓优先＋自动求解**，重新载入模型或点击 Generate baseline。默认载入和baseline使用同一纯几何入口；不是新增一个需要找到才能生效的隐藏预设。显式紧凑/诊断求解器保持原语义，不声称获得本版的特征保护。

选中主面时，“选择与对应”显示保留孔数、边界变化及孔面积比例。暂停/播放、几倍速、落位渐隐、框选、自由相机和原有填空顺序没有改动。相机不会因为新求解自动受动画绑定。

无需npm可打开根目录 `unfold-lab.html`。受file://限制时运行 `node scripts/serve-unfold-lab.mjs`。该离线页使用实际生产Worker/WebGL，可加载内置的无UV人台/头盔，不等于通用GLTF/FBX/React主入口认证。

完整Studio仍使用 `npm install`、`npm run dev`。本环境依赖安装再次超时，build仍为 `vite: not found`；不将离线浏览器测试称为完整React/Vite构建通过。

## 复现与参考文件

```bash
npm run test:feature-sheets
npm run test:geometry:real -- --out validation/local-real
npm run lab:build
# 无硬件GPU的测试环境可以显式加 CHROME_SOFTWARE_WEBGL=1
npm run test:feature-sheets:browser
node scripts/restore-feature-results.mjs
```

恢复脚本无需网络，得到 `results/v0.4.21/*-generated.obj`；人台复用旧版相同的压缩文件，避免重复占空间。Studio会忽略导入OBJ的UV并重新生成；查看精确参考布局请用外部UV查看器。模型原UV从未作为恢复路径使用。

## 验证边界

包含未见过的弯曲双孔/三孔壳体、真实护目镜旋转/缩放/改名、源UV getter禁止读取、硬切线与取消、齿轮Low/Medium、最终输出篡改拒绝。完整模型六条无UV泄漏路径实际执行。浏览器测试范围及失败记录见 `validation/v0.4.21/` 和最终ZIP验收记录。

首轮软件WebGL在全头盔线框/背景均显示时，5秒内没有观察到播放推进；没有把这项失败算作通过。关闭背景/线框的功能检查与独立相机回归分别记录；不能据此保证大型模型GPU流畅性。
