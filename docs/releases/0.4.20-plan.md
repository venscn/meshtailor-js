## 本轮硬约束

- 自动载入、Generate baseline、重新生成共用纯几何路径。
- 禁止源 UV 坐标、索引、切缝、岛分组提示和任何源 UV 回退进入生成；旧浏览器配置必须迁移。
- 后处理只接收本次工具生成的 UV，不得偷偷从输入模型取 UV。历史源码/测试可保留用于审计，但运行入口拒绝旧源 UV 操作。
- 改变真正的组分界和切缝，而非平滑屏幕轮廓；保留所有原顶点与面，不暗中重网格。
- 结构分组、必要开缝、参数化、排布分别记录。数值/边界失败不被笼统当成要切碎。
- 候选和最终映射均检查切割边界、三角形翻面、退化、重叠和面积塌缩。投影不是无条件成功出口。
- 同一几何携带原 UV、删除 UV、随机 UV、抛异常的 UV getter，生成都不得依赖 UV；真实两模型比较结果哈希。
- 保留旧 tag，按逻辑小步提交；最终 ZIP 关闭后校验 CRC、解压、git fsck、重新执行专项。

## 实现次序

1. 复现旧 baseline 和无提示剥展，建立几何边界粗糙度/面覆盖基准。
2. 输入白名单与统一 Worker/默认载入/按钮/CLI 路径，去掉源提示及旧恢复出口。
3. 所有参数化候选使用统一边界契约；开放 genus-0 多边界 LSCM，不为 solver.disk 前提无条件切孔。
4. 连续结构分组与图割边界正则化；组内切缝增加切向连续代价，保护真实特征和用户硬锁。
5. 真模型 no-UV 回归、界面回归与正确边界展示，文档/版本/归档验收。
