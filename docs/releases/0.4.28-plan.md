# 闭合管状曲面的条带展开（实施目标）

v0.4.27 的 Medium 三叶结实际走了通用 tree/cotree 切图，再从 Tutte 圆边界种子做自由 ARAP。返回一岛、局部方向拉伸较低，但真实 UV 面积/包围盒面积只有 5.7643%，不具备管身方向与周向的边界含义。原环带识别只接受两条现成边界，闭合管身直接跳过。基线日志为本轮真实执行，不是对截图猜测。

实现：从真实边图追踪近圆形横截面、验证完整周期截面族；选择一条纵向连续切缝和横向截面切缝；沿累计管身长度与累计截面周长建立矩形条带。检查环的覆盖、邻接、无分支、跨环对应闭合、每个面只覆盖一次，以及最终映射畸变与全量 UV 有效性。无法可靠识别时不强制矩形。没有读取源 UV、顶点编码、模型名称、生成器参数或种子 UV。

矩形长宽由几何长度/周长决定，不强制拉成正方形。不保证弯管是无拉伸可展曲面；必须报告面积密度与各向异性。允许显式增加横向分段，以排布效率换取额外接缝，不在填空操作中偷偷分割。

验收：Low/Medium/High 三叶结、不同扫掠曲线的管、圆环、不同对角线/重编号/旋转/缩放/污染 UV、硬缝/取消、非管状反例、生产 Worker 后缝合/填空以及正确人台/头盔三种 UV 输入。交付保持 Git 小步历史及现有工具显示行为。
