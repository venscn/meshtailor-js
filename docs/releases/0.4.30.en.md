# v0.4.30 · Equal-width profile strips and hole-preserving rings

**English summary** | [简体中文 · original release notes](0.4.30.md)

This is an English summary of the current release, not a full translation of the historical release notes or validation logs. The [original validation record](../../validation/v0.4.30/README.md) preserves the tests, failures, corrections, and environment limits reported for that release.

## Repeated sidewall profiles become rectangles

The Medium **Mechanical assembly** example has 22,528 triangles and 16 islands after stitching. Its central hole wall contains 2,304 triangles, 192 circumferential generators, and seven identical profile layers. The wall includes end bevels, so a straight cylinder or cone fit cannot represent it. The previous free-boundary LSCM result had a widest-to-narrowest generator ratio of **1.48328523878**.

The new strategy recognizes complete circumferential sections, an unbranched profile graph, and a complete generator from geometry and edge adjacency. It does not read model names, example metadata, original UVs, original seams, or original islands.

For a surface of revolution with metric `ds² + r(s)² dθ²`, the mapping uses:

```text
h(s) = ∫ ds/r(s)
R = total profile length / total h
u = R × circumferential angle
v = R × h(s)
```

The opening follows an actual complete generator made of mesh edges. The four rectangle edges follow the profile and circumferential directions, and all bevels and triangles remain. For the central hole wall, the generated width ratio is **1**, the rectangle aspect ratio is **8.12199510936:1**, and the maximum local directional stretch ratio is **1.02957672438**. Bevels at different radii require some distortion to fit an equal-width rectangle; this mapping is not fully isometric.

All three 2,304-triangle hole walls become complete rectangles. Their aspect ratios reflect their individual geometric profiles; they are not forced to equal dimensions.

## Shallow radial rings retain their holes

For an axisymmetric profile extending mainly in the radial direction with two complete boundary loops, the strategy first considers an annulus with `rho = inner radius + cumulative profile length`. This keeps the outer boundary and inner hole, including profiles that fold back through their thickness, without stacking them through direct projection.

The three 288-triangle rings in the correct Corset fixture each remain one island with two boundary loops, without a radial opening. Preserving the radial profile length has a circumferential distortion cost: maximum local directional stretch is approximately **2.25084**, compared with about **1.98 / 1.90** for the earlier opened shoulder-ring mappings. Candidates exceeding the user's distortion threshold are rejected. Flip, degeneracy, and overlap checks are not relaxed to obtain a ring shape.

The profile direction determines whether a rectangular sidewall or annular candidate applies. This does not imply that every cylinder should become an annulus or that every surface with a hole can retain it in a single island.

## Geometry and output checks

- Seams must follow mesh edges, and every face must appear exactly once.
- Triangle validity, simple boundaries, distortion, and area-collapse thresholds are checked.
- Rectangle boundaries must correspond to full generators and both circumferential boundaries, with valid internal connectivity.
- Per-vertex reference coordinates and all face-corner continuity, holes, openings, and face sets are checked after packing, stitching, repacking, and gap filling. Post-processing may apply only whole-island rotation, translation, and uniform scaling.
- Original 3D vertices are retained. Failed candidates do not fall back to source UVs.

Original, absent, and randomized UV variants of both correct real fixtures produced identical seams, every face-corner coordinate, and OBJ output through six complete production Worker generation paths. Those checks cover generation; time-limited gap filling was not used as evidence of deterministic output.

## Use and inspect the results

Keep **Repeated-profile metric unfolding (equal-width sidewalls / hole-preserving rings)** enabled under **UV → Structural templates**; it is enabled by default. Use the hand-drawn contour priority target with automatic solving, then reload Mechanical assembly or select **Generate baseline**. The Inspector reports profile layers, rectangle dimensions, face count, distortion limit, and hole preservation.

The Studio and offline workbench share the algorithm. Disabling the option explicitly selects the earlier free-boundary path for comparison. Existing explicit one-/two-piece controls, per-island face budgets, cone sectors, and closed-tube transverse segmentation remain available.

From the repository root, the relevant commands are:

```bash
npm run check:geometry
npm run test:revolved-profile
npm run test:revolved-profile:worker
npm run lab:build
npm run test:revolved-profile:browser
npm run results:profiles
```

`results:profiles` restores SHA256-verified reference OBJ files into `results/v0.4.30/`. Inspect their unchanged layout in an external UV viewer. Importing them into this application intentionally ignores their existing UVs and generates a new atlas. These stored reference outputs are not a runtime fallback.

## Results and historical validation limits

The factory-default Corset result retains all **18,324 faces**, with **81 islands** before stitching and **80** after stitching. FlightHelmet retains all **94,722 faces** and **191 islands**; its generated OBJ is unchanged from v0.4.29. This release does not claim improvements to its other general curved surfaces.

The release record reports **22** new profile unit checks, **9** Worker checks, **12** completed browser checks, six real-fixture UV-isolation runs, and independent Shapely/GEOS checks of four actual OBJ outputs with zero positive-area overlap at a `1e-14 UV²` tolerance. Browser validation exercised the offline workbench with production modules and Chromium software WebGL; it was not certification of the complete React Studio entry point.

The first concurrent browser attempt stopped responding after four checks and was canceled; it is retained as incomplete. A later serial run completed all 12 checks. A Worker invocation interrupted by an external 120-second limit was subsequently completed in a separate session. Historical stale assertions and an incorrect pre-packing overlap test were corrected with the original failed logs retained.

At release time, `npm install` exceeded a 25-second limit, the full build failed because Vite was unavailable, and the full type check failed because Node types were unavailable. Core compilation and offline browser checks were not presented as successful full Studio checks. Later maintenance validation is recorded separately in [open-source preparation](../OPEN_SOURCE_PREPARATION.md); these historical limits remain part of the release record.

Recognition requires complete circumferential section edges and unbranched profile adjacency, with radial/axial residuals limited to `5e-5` of the maximum radius. Noisy, eccentric, branching, or irregularly remeshed inputs may use the general geometry path. Real teeth and folds are not forced into rectangles, and steep cone sectors are not compressed into rectangular strips. General semantic patterns, globally optimal packing, and texture baking remain outside this release's scope. Timed packing samples are not a guarantee of identical gains across machines.
