## Using and distributing the project

MIT permits use, modification, redistribution, sublicensing, and commercial use. Copies or substantial portions must retain the copyright and permission notices. Include the root `LICENSE` when distributing project source or compiled code. The license provides the software without warranty; the full [license text](../LICENSE) governs these terms. See the [Open Source Initiative's MIT text](https://opensource.org/license/mit).

The root package and all seven workspaces declare `"license": "MIT"`. They retain `"private": true` to prevent accidental npm publication; that setting does not change the project's license.

## Third-party assets and dependencies

The bundled Corset and Flight Helmet model geometry remains under **CC0-1.0**, including outputs derived from that geometry. It is not relicensed under MIT. Model sources, locations, changes, and upstream metadata exceptions are documented in [Third-party assets](../THIRD_PARTY_ASSETS.md).

Dependencies installed through npm retain their own licenses. When redistributing a build that contains dependency code or third-party assets, preserve the notices required by each upstream license. The project's MIT notice does not replace those notices.

## Contributions

Contributions of code, original documentation, and original assets are submitted under the project's MIT License. Submit material you have the right to contribute and identify any third-party material, its source, and its license. Preserve existing copyright and license notices.

The project does not require a separate contributor license agreement (CLA) or Developer Certificate of Origin (DCO) sign-off. See [Contributing](../CONTRIBUTING.md) for the development workflow.
