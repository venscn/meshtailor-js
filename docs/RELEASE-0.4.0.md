# MeshTailor-JS v0.4.0

本版针对 v0.3.0 两个具体缺陷：看不清面片如何折开，以及投影 UV 重叠 / 退化 / 等格排布。

## 功能变更

默认动画改为“分块陈列 → 转向 → 沿共享边铰链展开 → 刚性平面网停留 → UV 形变 → Atlas 排布”。支持按根面向外展开、铰链剩余角度、紫色临时断边、自动适配当前片块范围；保留单个、多选、全部、逐个、同时和反向进度。新增三块真正弯折的带状示例，原六岛立方体继续保留。

生成 UV 不再走平面投影。新增面角切割拓扑、盘检查、LSCM、凸边界 Tutte 回退、翻面 / 退化 / 正面积重叠验证、可配置补切，以及保持岛平均面积比例的 MaxRects 排布。新增实际 UV 占用率、包围盒占用率、求解方法、形变与补切诊断。OBJ 导出保留 UV 岛身份，包括原始 UV 坐标重叠的不同岛。

新增独立 `unfold-lab.html` 和源码 / 构建器：无需 npm 运行依赖即可检查同一套核心算法。真实浏览器 Worker 使用离线 classic 封装；主 Studio 仍使用 Vite module Worker。离线页仅支持 OBJ / 内置网格，不取代主 Studio 的 FBX / GLB 导入。

## 维护

继承 v0.3.0 的 Git 仓库；本版使用独立附注 tag `v0.4.0`。所有旧 tag 不移动，额外将 v0.3.0 固定到 Git 检查基线。ZIP 包含 `.git/` 及打包时生成的完整 bundle；功能、修复、测试、版本和文档分步提交。不要重新初始化仓库。

## 使用

主界面：`npm install`，`npm run dev`；顶栏 `Studio · 0.4.0`。

无需安装运行依赖的预览：打开根目录 `unfold-lab.html`。浏览器限制 file:// 时可执行 `node scripts/serve-unfold-lab.mjs`。先用三块折角带，选择一个岛或全部，拖动 28–70% 看刚性折开，停在 75% 检查真实平面网，最后比较 100% 与右侧 UV。

详细算法、配置、截图、局限在 `UNFOLDING_AND_UV.md`；测试记录在 `VALIDATION.md`。本版没有训练 MeshTailor 神经网络，也没有声称官方论文质量复现。
