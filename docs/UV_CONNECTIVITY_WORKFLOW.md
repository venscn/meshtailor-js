# UV 连通优先前处理、邻岛缝合与新 atlas 分页

适用版本：0.4.8。三种操作独立存在，不能把视觉上重叠、同页摆放和拓扑缝合混为一谈。

## 先区分四个概念

**原始 UV 岛**由逐面角 UV 与接缝关系定义；两个岛占用同一坐标区域，仍是两个岛。**材质分框**只是查看源 UV 的方式，不修复重叠、不减少岛数。**新 atlas 页分组**决定哪些岛放在同一页，也不减少岛数。**邻岛缝合**才会移除共同接缝、重建对应并重新参数化，成功后岛数减少。

Extract 的原始材质分框继续保留，以便与原资产对照。本版不再让这种分框看起来像已经完成了碎岛优化：显示实际岛数，并在每个真实源材质域内跨岛检查正面积重叠。计数达到100对时显示“至少”，不是冒充完整数量。统一镜像可以是有意复用；有重叠不自动等于资产错误。审计不改变原 UV。

## 入口与推荐操作

在左侧“UV”工具页的“减少碎岛 · 前处理 / 后处理”中：

| 操作 | 输入 | 实际动作 |
|---|---|---|
| 前处理：连通优先重分割 + 自动缝合 | 原始3D网格 | 清除当前接缝方案，从几何连通分量开始求解；只做必要补切，然后尝试邻岛缝合 |
| 后处理：缝合当前邻岛 | 当前已完成的UV快照 | 保留当前分割作为起点，移除可以安全连接的共同接缝，重新求解和排布 |
| 只重排当前岛 | 当前已完成的UV快照 | 岛数和裁切关系不变，只重新排布；适合岛之间叠放但各岛自身有效的情况 |

新操作需要主动点击。原来的 Generate baseline / 自动大块入口继续使用其当前配置；仅升级或再次点击 Extract，不会自动把原始碎岛重新缝合。前处理按钮会明确启用 `initialSegmentation=connected`、`postMerge=true` 并替换现有接缝，不偷偷保留先前非常碎的切法。

处理后可再次 Extract 回到原 UV。后处理捕获当前快照，不以一个重新生成的 baseline 冒充后处理；失败会恢复上一份完成结果并显示错误。原始网格位置、三角面和原 UV 不被覆盖。

## 前处理：不要一开始就把折角全部变成接缝

连通优先模式绕开初始法向锥区域分割，先尝试每个真实几何连通分量。闭环、孔洞等优先沿已有的开缝修复路径处理；拓扑、求解有效性、面数预算或配置的形变约束确实要求补切时才拆开。

它不是“一个物体必须只有一个岛”。不跨原本不相连的网格组件焊接，不从UV坐标接近推断3D连接，不做语义部件识别。输入若已经被拆成很多断开的几何壳层，需要先检查导入拓扑，不能靠UV参数把它们当成相连。

## 后处理：以真实共享边为候选，逐次验证

1. 建立岛邻接图。只有同一真实网格边两侧、相反绕序、各有一个三角面的岛才相邻。单点接触、空间重合但独立的壳层、非流形边不构成缝合候选。
2. 根据共享边界长度、两个岛的周长与边界法向一致性计算亲和度。优先尝试共同边界占比较大、方向更连续的邻岛，而非优先相同材质编号。
3. 复制当前接缝集，移除候选共同边界，重新构造切割后的面角拓扑；必要时尝试开缝，但必须形成一个可参数化的盘状块。
4. 实际运行现有 LSCM / Tutte 求解，检查所有三角面，包含退化、翻面、正面积自重叠和配置的形变、长宽比、填充率约束。
5. 所有检查通过才替换当前结果；否则保留旧岛，记录拒绝原因，继续尝试其他邻岛。没有通过减少有效性检查来强行达到目标岛数。

这是确定性的贪心合并，不保证全局最少岛数或全局最优裁切。它可能改变岛形状、转向与纹理布局；不是只把两块平移到接缝碰在一起。

### 可控参数

默认尝试预算128，范围0–2000；目标岛数默认1，是停止目标而非承诺。预算耗尽会明确报告，继续点击后处理可从当前结果接着尝试。仍受UV总计算预算限制，取消/超时不发布未完成的半成品。

默认允许跨旧材质边界缝合，因为输出是新atlas；可以启用“后处理不跨源材质边界缝合”。API的 `mergeOptions.protectedSeams` 可保护已存在的真实接缝，不能用来悄悄创建一条新的内部切口；本版没有新增可视化逐边锁定编辑器。

同岛内部已经折叠、混合翻面、退化或自重叠的源 UV，不应让“重排”伪装修好。本版后处理会明确拒绝该输入，提示改用从3D重新求解的前处理。仅岛与岛之间重叠、各岛自身有效时，可以直接后处理。完整反向绕序的镜像岛可用于新atlas，方向规范化不会修改源UV。

## 新 UV 页按连接关系分配

**单页（默认）**：所有结果岛排入一个0–1 atlas；不相连的几何仍是独立岛，但允许同页摆放。

**连接紧密的岛优先同页**：对真实邻接图按亲和度从强到弱构造生成森林，保留紧密连接于同一页。目标页数是软目标：不跨完全断开的几何组件强行组页，因此实际页数可能高于请求值；不会把不能实现的目标静默假装满足。

**每个几何连通组一页**：同一几何连通组内的所有结果岛共页；不再按源材质枚举分页。

分页不会自动减少岛数。默认最大64页；当选择的连接策略需要更多页时明确报错，可选择单页而不是隐式改变连接关系。按连接优先可能使各页大小不均，不是以页面填满为最高目标。

各页使用同一平均纹素密度，排布时保留留白；不是把每页独立放大到填满。页面诊断记录页数、每页岛与面数、占用率、共同缩放、来源材质ID，以及留在同页的共享边界长度比例。

## 导出与贴图

源UV模式导出原坐标、原材质域，不把显示分框偏移写进去。新atlas则写自己的 `atlas-page-N` 域，页内UV保持0–1，OBJ用独立的 `usemtl` 标签区分页；旁边展示页的平移不是实际UV值。新单页也使用新域，避免缝合结果回读后又沿旧材质边界拆开。

**新atlas通常需要重新烘焙贴图。** 本版不自动生成新贴图/MTL，不保证保留原来的贴图绑定。页面诊断保存来源材质ID集合，不声称用这些集合恢复完整原贴图。原始输入仍在内存中保留。后处理输出、3D动画目标、右侧UV、拾取与导出共用对应数据。

## 实验与限制

提供“重叠碎片 · 测试片”：两个独立弯曲面板，共12个三角形、12个故意重叠的源UV岛。同一真实浏览器中，重排后仍是12岛；缝合后是2岛，可按连接分成2页；重新Extract仍回到原来的12岛和原有重叠。这是明确的合成验证，不是Corset或FlightHelmet替代资产。

内置Low齿轮/程序服装/三叶结/机械件的对照结果和耗时见 `VALIDATION.md` 与 `validation/v0.4.8/quality.json`。岛数减少不保证占用率更高，某些合并会增加局部形变、计算量或动画的刚性临时断边。大网格更容易触发尝试/面数/总时间预算。

本轮没有拿到真实Corset与FlightHelmet二进制，也没有完成React/Vite主界面构建。不要把合成浏览器测试和四种内置网格的结果当成这两个资产已经实测修复。

本地真实资产诊断（需要已安装依赖和实际资产）：

```bash
npm run assets:download -- --only corset
npm run test:sample-asset -- --asset corset --pipeline connected --report corset-connected.json
npm run test:sample-asset -- --asset flight-helmet --pipeline stitch --report helmet-stitch.json
# baseline / connected / stitch / repack 四条路径分别记录，不能混称一个流程。
```

## 代码入口与方法参考

`chart-adjacency.ts` 负责真实邻接；`source-audit.ts` 负责原UV跨岛审计；`chart-merge.ts` 负责事务式缝合；`atlas-pages.ts` 负责连接分组与统一密度；`postprocess.ts` 负责基于快照的后处理；`unwrap.ts` 接入前处理。Studio和离线页复用这些模块及生产Worker。

相关背景资料：CGAL Surface Mesh Parameterization手册（拓扑前提、LSCM/Tutte与畸变取舍）：https://doc.cgal.org/latest/Surface_mesh_parameterization/index.html 。xatlas公开接口中的chart/atlas选项： https://github.com/jpcy/xatlas/blob/master/source/xatlas/xatlas.h 。这是本工程的独立JS/TS实现，没有引入或声称完整复现xatlas算法，也没有新增学习权重。
