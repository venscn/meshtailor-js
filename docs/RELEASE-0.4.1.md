# MeshTailor-JS v0.4.1 — 大网格 UV 计算卡住修复

## 对应问题与确认范围

用户加载 Flight Helmet 后一直看到“正在计算同一份网格 / UV 对应数据”。该文本在旧版覆盖拓扑准备、LSCM/Tutte 求解、交叠检查、排布和铰链准备的整个过程，不能辨别线程未启动、正在计算、计算过慢还是已失败。

本轮确认并修复的是源码里的性能瓶颈和任务生命周期缺陷。**未能取得 Flight Helmet 原始几何二进制，尚不能确认该资产在用户机器上的确切卡点，也不能声称该模型端到端测试已通过。** 不使用程序生成模型冒充飞行头盔。源码及测试基于此前发布的 v0.4.0 继续维护。

## 修复内容

### 计算不再无限等待且看得见阶段

新增共享 UV 任务客户端，用于 React hook 和离线实验页。默认求解预算 120 秒；主线程在预算外增加 1 秒传输余量，并有 15 秒启动响应保护。达到上限会明确失败并终止 Worker，不会把部分 UV 当成完整结果。界面的预算设置范围为 5–900 秒；取消直接终止线程，不依赖正在同步求解的线程接收 cancel 消息。

状态显示阶段、真实计数与耗时：输入 / 源岛 / 切割拓扑 / 参数化迭代 / UV 有效性 / 旋转 / 排布轮数 / 3D–UV 对应 / 铰链 / 传输。更新最多约每秒十次。“已接受有效对应面”不是整体百分比：面数完成后仍需排布和铰链处理。不提供虚假的剩余时间。

取消、预算超时、启动无响应、Worker 错误、消息解析失败、协议不匹配和输入克隆失败都结束任务；模型或设置变化清理旧线程，迟到消息不能覆盖新结果。取消后可“重新计算 UV”。使用“网格原始 UV”必须主动选择，不会自动替换重新求解；原布局不被修复、重排或认证无重叠。

### 大网格与大量 UV 岛性能

LSCM 稀疏行改用连续类型数组和索引循环，减少迭代中的对象访问与回调；保持原求解方程和有效性门槛。超时异常不再被数值回退吞掉，也不会触发新一轮递归补切。

排布模式新增 Auto / MaxRects / Shelf。Auto 在岛数大于 256 时选择面积感知 Shelf，较小输入保留 MaxRects。显式 MaxRects 超过 1,024 岛会提示改用 Auto/Shelf。新策略保留旋转、统一纹素密度、共同缩放和留白，不删除面、不降低模型精度、不独立压缩 U/V。两种方式都不是全局最优多边形嵌套，结果与占用率可能不同。

同一个 2,000 岛测试，旧 MaxRects 在 35 秒进程上限内未完成；本轮最终报告中新路径约 90.6 毫秒完成。该数字是排布耗时，不包含 UV 求解，不是任意模型的性能承诺。

## 实际回归

90,112 三角形的程序生成 High 多部件机械网格，运行生产 UV Worker：完整生成约 9.70 秒，462 个岛、71 条进度消息，全部源面恰好一次映射并通过 UV 有效性检查。原始 UV 路线约 2.73 秒。新结果没有通过减少面片或取消翻面/交叠检查取得。

实际浏览器 Worker 已验证：大网格运行时页面响应、取消、重试、预算失败、原始 UV 路线和失败后重新生成。另用故意不返回的同步循环，验证主线程硬超时确实能终止 Worker。浏览器测试运行离线实验页及共享模块，**不是完整 React/Vite 主界面认证**。

完整报告与执行限制见 `docs/VALIDATION.md`、`docs/validation/v0.4.1/`。本轮 npm 安装在 20 秒限制内未完成；远端 raw 文件 DNS 解析失败。未验证完整 UI 类型检查、Vite 构建、主 Studio module Worker 打包加载、真实 GLTF/FBX 导入及真实 Flight Helmet。程序不需要用户在启动时安装测试用 Xvfb。

## 使用

解压到新目录，保留 `.git/`：

```bash
npm install
npm run dev
```

确认顶栏 `Studio · 0.4.1`。加载飞行头盔后查看“UV 计算任务”，排布先保留 Auto。超时会显示最后阶段；可在“UV 求解与排布”调整预算后重试。不必为了退出计算刷新整页。

只检查模型已有的 UV 与 3D 对应时，选择“使用网格原始 UV”；这与生成新的 UV 是两条明确分开的路径。离线实验页 `unfold-lab.html` 同样新增状态、预算和取消，但不包含远端 Flight Helmet 模型。

## 飞行头盔专项诊断入口

真实资产的本地回归已提供但本轮未执行。它使用实际 GLTF 导入路径和生产 Worker，记录资产 SHA256、面数、岛数、阶段时间和错误。安装依赖后：

```bash
npm run assets:download -- --only flight-helmet
npm run test:flight-helmet -- --report flight-helmet-report.json
```

已有 geometry-only GLB 可跳过下载：

```bash
npm run test:flight-helmet -- --file path/to/flight-helmet.glb --budget-seconds 120 --report flight-helmet-report.json
```

默认依次测试 generated / source；可用 `--target generated` 或 `--target source` 单独检查。失败退出非零，不掩盖问题。这个脚本不能代替用户浏览器的 React UI 回归。
