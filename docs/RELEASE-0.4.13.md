# v0.4.13 · 面积队列、倍速、局部避遮挡、框选与自适应填空

本版沿 v0.4.12 的 Git 历史继续开发。使用包内同一份哈希锁定的正确 Corset / FlightHelmet glTF、bin，未读取早先错误的下载网页。没有引入官方学习模型或新的运行时依赖。

## 1. 播放队列：按真实 3D 表面积排序

全部、多选、框选产生的播放队列，均按源三角面的 3D 面积总和降序；同面积按岛 ID 稳定排序。不是面数、UV 面积、包围盒面积，也不是点击次序。源位置统一归一化只改变公共尺度，不改变面积排名。单岛检查不变，反向播放沿同一条时间线倒放。

面积按几何 snapshot 缓存。改相机、改变动画进度、切换倍速不重新排序或重算 UV。几何姿态、铰链、阶段按钮和接力提示用同一个排序后的队列。默认依然是85%接力，最多两块活动岛；未开始的岛保持源3D，完成的保持最终UV。

## 2. 播放速度

0.25×、0.5×、1×、2×、4×、8×、16×、32×、64×。主 Studio 位于视口下方播放控制条；离线工作台位于“动画 / 播放速度”。

倍速仅乘在可见窗口的 RAF 播放时钟，不缩短铰链某一阶段、不重新设置每岛时长、不清空已压缩的静止区间。播放中调整不暂停、不归零、不重置相机或 snapshot。总时长和剩余时间显示当前倍速对应的实际播放时间，同时保留1×基准。

例如1×队列1327.8秒，对应8×约166.0秒，16×约83.0秒，32×约41.5秒，64×约20.7秒。这是时间线换算，不是任何GPU上的帧率保证。过高倍速与低帧率结合时会跳过中间显示帧，不能保证每个小岛都有足够可见帧；需要检查细节时降低倍速或暂停拖动。

## 3. 当前岛局部避遮挡

默认启用“当前播放岛 · 避遮挡 / 周边模型局部散点淡出”。球心从**当前已变形顶点**的包围盒中心计算，半径覆盖当前岛并乘用户参数；不是固定源中心。默认范围1.2倍当前岛半径，可调1–3倍；遮挡面默认保留12%的屏幕采样点，可调2%–80%。边缘采用平滑过渡，接力中的两块活动岛均受保护，不会相互被此效果淡出。

用稳定4×4有序散点丢弃片元，而不是依赖透明三角面排序。球内**其他岛的局部片元**被处理，球外部分仍保留；当前运动岛保持实体。开始/结束附近淡入淡出，暂停在中间姿态仍可观察。主表面与叠层检测的深度预通道一致处理散点，不会留下已淡出的“假遮挡”。

不修改模型、UV、铰链路径、导出或用户相机。它是显示辅助，不是几何挖洞或全局透视；范围外的前景仍可能挡住，长展开网也可能产生很大的球，可调小范围或关闭。所有现有自由相机规则保留。

## 4. 铰链还在转动时就显示叠层

默认“自动 · 运动岛视线叠层”：存在活动岛时，对活动岛内部的当前视线覆盖层数作诊断；其余等待岛不参与运动诊断。没有活动岛的端点，自动回到原近共面模式。

显式“同岛近共面”、“视线叠层（所有已选岛）”和“关闭”仍可选。橙色斜纹2层、玫红交叉纹3层以上保持。非平行三角面尚未展平时就会显示投影叠层，不再被近共面的法向/距离门槛过滤掉。

**投影遮挡不等于几何相交。** 默认不声称精确3D碰撞、深处不可见重叠或跨岛接触；窗口缩小、诊断缓冲区分辨率和亚像素面都会影响显示。最终UV仍依靠几何检查，不靠“没有条纹”证明有效。

## 5. UV框选与两级检查

| 操作 | 结果 |
|---|---|
| 左键直接拖拽 | 用框触及的岛替换选择，无快捷键 |
| Shift拖拽 | 加选 |
| Alt拖拽 | 对框内的岛逐个反选（已选取消、未选加入） |
| Ctrl / Command拖拽 | 减选 |
| Esc / pointercancel | 取消当前框选手势，保留先前选择 |

按实际三角形与矩形的交集命中，不用岛包围盒填充空洞；任一面被框触及即选整岛。反向拖拽同样有效，手势超过4 CSS像素后才算框选；在岛上按下也可直接拖框，不必寻找空白处。一次释放提交一次选择事务，选择时清空三角形检查，不默认选面。

轻点继续遵循“首次只选岛→再次点击选三角形→再点同一三角形取消面”的原规则。更换网格/UV snapshot 时正在进行的手势被丢弃，不把旧面编号应用到新数据。框选改变队列时暂停并从新队列开始；纯三角形切换不改时钟或相机。

## 6. 多轮填空：失败大岛不再阻塞后面的岛

“UV → 空白精排 · 大岛优先”。从当前有效单页atlas开始，默认不改岛数、切缝或源几何。

1. 优先把当前排布作为种子；当前栅格不容纳时再完整轮廓重排，不为重复点击先归一化掉已有收益。
2. 每轮按真实3D面积降序遍历；先试当前位置扩张，再试其余岛不动的局部空位，最后才重排较小岛的后缀。
3. 每个岛维护**自己的步长和失败状态**。大岛8%失败时，下轮可试4%、2%、1%、0.5%；其他小岛不因它失败而停止，也不被强迫用相同步长。
4. 一轮中某个岛失败仍继续下一个；达到密度/增益上限的岛跳过，不浪费扩张试装。新的排布产生空间后，后续轮仍可再次尝试大岛。
5. 所有岛都能放下且全量验证通过才提交；不缩小小岛、不拉伸单独U或V、不删除面、不用重叠刷占用率。

现在试0°/90°/180°/270°，不镜像。默认8轮，0.5%最小面积步长，自动尝试预算max(256, 岛数×8)，默认搜索15秒。面积步长仍8%、单次增益/密度限制仍1.6倍；这些是面积比例，不是边长比例。轮数/试装/搜索时间达到上限会明确报告；只有所有可增长岛的最小步长也真正尝试失败，才报告本次方向与分辨率下无改进，**不宣称全局最优**。

搜索使用保守轮廓栅格、留白和整图三角形检查。连续角度、精确全局多边形嵌套、多页联动、语义重要性和自动烘焙不在本版范围；邻居布局偏好可能让位于紧凑性。

### 大块旧接缝试验（明确可选，默认关闭）

仅在独立“填补空白”操作勾选生效：从前三大岛中找占全模型3D表面积至少12%的岛，**只恢复源UV原来已经存在的边界**。每次候选分成两块，子块至少各占父块25%、至少32面；两块必须连通，一次操作最多接受新增一个岛。

最多尝试两候选，每候选最多15秒/4轮（仍受任务整体预算约束）。完整试装必须比不切方案提升至少1个百分点，且所有面不缩小、不超过本次初始面积上限，并通过UV检查，才接受；否则原样回退。不会切小岛、递归撒碎片，也不会自动把不同语义块重新缝成新的组合。

真实人台和头盔各找到一个符合条件的候选，实测均没有达到所需收益，**均回退，79/130岛不变**。这不证明其他切缝绝对无收益。通用接受路径有完整质量门槛；本轮没有获得真实资产上被接受的新切缝样本，不声称该分支提升了它们的占用率。

## 7. 真实模型结果及预算

用包内同一份正确hash锁定原始glTF/bin运行生产source-atlas Worker，再执行精排。测试参数：512格、10轮、最多1500次、90秒精排搜索、300秒整个任务预算。**不是界面默认15秒的性能承诺**；对照旧版测试为4轮、128次。

| 项目 | Corset | FlightHelmet |
|---|---:|---:|
| 三角面，全部保留 | 18,324 | 94,722 |
| UV岛，未增加切缝 | 79 | 130 |
| v0.4.12已交付精排占用率 | 78.5223% | 71.6196% |
| 本版测试占用率 | **83.9816%** | **73.5795%** |
| 本版搜索尝试 | 544 | 806 |
| 完成/进入轮数 | 10 | 7 |
| 停止原因 | 轮数上限 | 搜索时间预算 |
| 局部扩张接受次数 | 390 | 488 |
| 失败大岛后继续尝试小岛 | 531 | 787 |
| 精排含最终几何检查 | 约21.70秒 | 约93.23秒 |
| 完整Worker流程 | 约23.80秒 | 约112.14秒 |

这些结果同时改变了算法和搜索预算，不能把全部差值解释成同预算纯算法提升。计时是本环境单次记录，最后验证时间在搜索预算之外。新尝试未达全局饱和；可以提高预算/轮数或再次对当前结果操作。

独立GEOS/Shapely检查导出的实际OBJ：两者翻面、退化、正面积重叠为0，源顶点与面顺序不变；正面积交集阈值1e-14 UV²。纹理占用按实际三角形面积算，不是包围盒总和。Python只是额外QA，不是运行依赖。改变UV后仍需重新烘焙已有贴图。
