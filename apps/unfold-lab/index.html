本地与内置模型

此离线页支持 OBJ；FBX / GLB 等仍在主 Studio 导入。内置样例均不需要联网。

裁切与展开

自动重分割替换当前裁切，原始 UV 仍保留。整理生成新 atlas；原样检查才保留原布局。
前处理 / 后处理
缝合会移除接缝并重新求解；重排不减少岛数。新 UV 需要重烘焙；原输入不变，原样检查可恢复原坐标。
空白精排 · 大岛优先 失败大岛不阻塞小岛；逐岛降低步长，四方向轮廓搜索，先局部扩张再重排。
实验：特别大岛恢复旧切缝默认关闭。只处理总3D面积≥12%的前3大岛；只恢复源切缝，两子块各≥25%。至少提升1个百分点才接受，一次最多新增1岛，不切小岛。
只移动、旋转和有界等比例放大，不改切缝，不缩小其他岛。面积放大 1.6 倍，边长仅 √1.6 倍。仅支持单页；多页请先只重排为单页。原 UV 重叠时须先整理。

面积与空间邻居 只重做含内部重叠/混合翻面/退化的原岛；其余形状保留，原输入不变。

默认严格等密度；2 倍面积只放大 √2 倍边长。全岛共同缩放。

UV 岛

先选 UV 岛，再点击岛内三角形；重复点击该面取消。Shift 增减岛。

播放与显示

未启动的岛保持原位，已完成的岛留在 UV。没有全体同时启动模式。 队列按原始 3D 表面积降序，点击顺序不影响播放。
运动判定容差按顶点及铰链变换判断；与相机、遮挡无关。绝对容差 1e-8 个归一化单位。
重叠与面片识别
当前播放岛 · 避遮挡当前形态中心的球形范围；接力中的两岛保持实体，不改变模型或相机。
检测容差过大会将靠近的平行面一起标记，不是精确自交验证。
橙斜纹：2 层；玫红交叉纹：3 层及以上。默认仅当前可见表层附近；视线叠层含普通遮挡。切换不暂停、不重算。
默认 12%，与岛数无关；0 禁用分离，不修改相机。
