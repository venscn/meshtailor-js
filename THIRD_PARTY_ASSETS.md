# Asset provenance and licenses

Last checked: 2026-10-08. The root [MIT License](LICENSE) covers project code, original documentation, and project-created assets. Third-party models retain their upstream licenses.

## Project-created assets

`examples/complex/*.obj`, basic geometry samples, and `apps/studio/public/assets/fixtures/garment-*.fbx` are generated by this project and use MIT. Run `npm run assets:generate`; file identities are recorded in [examples/manifest.json](examples/manifest.json). The FBX writer creates synthetic regression fixtures, not general FBX exports.

The README mechanical screenshot shows project-generated geometry in the actual workbench. It is not MeshTailor paper training data.

These models are already included in the repository:

- `examples/verified-models/`: pinned `.gltf` and `.bin` regression fixtures without textures. See the [fixture guide](examples/verified-models/README.md) for checksums.
- `apps/studio/public/assets/verified/`: derived geometry `.glb`, compressed geometry JSON, and a [manifest](apps/studio/public/assets/verified/manifest.json). Original UV and material/texture references are removed for default loading.
- `unfold-lab.html`: the offline workbench embeds the same geometry.
- `examples/generated-*/` and `examples/human-uv/`: some reference outputs retain this geometry with generated UVs. Generation does not relicense the original model assets.
- `validation/` and `docs/images/`: may contain screenshots and diagnostics of these models in this tool.

Upstream lists model-associated files under CC0-1.0 and metadocumentation under CC-BY-4.0, excluding logos and trademarks. This document is an original provenance summary with upstream links; it does not relicense upstream metadata as MIT.

Do not replace pinned fixtures with newer upstream `main` content. Reproduce geometry preprocessing with `npm run assets:geometry`.

## Optional online downloads

`npm run assets:download` fetches models from the same upstream and creates geometry GLB files without material/texture references. Downloads are opt-in, not startup dependencies. Companion receipts record source, credit, license, modifications, time, and SHA256. Upstream `main` may change, so downloaded files and pinned fixtures are managed separately.

## Dependencies

React, Three.js, Vite, and other npm dependencies retain their respective licenses. FBXLoader / GLTFLoader come from Three.js. The repository does not bundle Autodesk SDK binaries, neural checkpoints, or third-party fonts. README SVGs use system fonts.
