# Asset provenance and licenses

Checked: 2026-09-11. These notes distinguish generated files shipped in the ZIP from optional third-party downloads.

## Shipped assets

`examples/complex/*.obj` and `apps/studio/public/assets/fixtures/garment-*.fbx` were generated by this project. They are supplied under this project's MIT license, with reproducible scripts and hashes in `examples/manifest.json`. They are not scans or copies of MeshTailor's training dataset. The FBX files are synthetic parser regression fixtures.

The upstream license files distinguish CC0-1.0 model-associated assets from CC-BY-4.0 metadocumentation and exclude logos/trademarks. This document is an original provenance summary and links to, rather than redistributing, those upstream metadata files. Source statements should be rechecked when adding a different asset; a repository-wide license is not evidence that every model is identically licensed.

The opt-in downloader obtains the uncompressed glTF JSON and its geometry buffer, removes material/texture references, and writes a geometry-only GLB. This is a modified geometry-focused packaging, not the original complete textured asset. Source, credit, license, modifications, download timestamp and SHA256 are stored in the companion JSON receipt. Source URLs use the upstream main branch, so downloaded content can change; receipts identify the concrete bytes fetched by the user.

**No remote asset binaries were successfully downloaded in this assembly environment, and none are included in the ZIP.** Do not count the presence of catalog entries or mock download tests as a verified live download.

## Library code

Three.js FBXLoader / GLTFLoader are imported from the existing npm Three dependency; no Autodesk SDK binaries are bundled. React, Vite and Three retain their respective upstream licenses. No node_modules directory, neural checkpoint or copied third-party font is included in this release.
